9. nono — Sandbox a Nível de Kernel

  

  

    O nono usa Landlock (Linux ≥ 5.13) e Seatbelt (macOS) para enforcement
    irreversível a nível de kernel. O agente inicia sem acesso a nada — você concede explicitamente
    o que ele pode ler/escrever/conectar. Nem o próprio nono pode escapar depois de aplicado.

    Como instalar o nono
    


      Ubuntu / Debian:

      sudo apt update && sudo apt install nono

      ou via snap: 
      sudo snap install nono



      Fedora / RHEL / openSUSE:

      sudo dnf install nono



      macOS:

      brew install nono



      Via Cargo (qualquer plataforma):

      cargo install nono



      Verificar suporte a Landlock (Linux ≥ 5.13):

      uname -r
       — kernel deve ser ≥ 5.13

      nono setup --check-only



      Rodar o openclaw com perfil built-in:

      nono run --profile openclaw -- openclaw gateway



      Docs:
      nono.sh/docs  | 
      github.com/always-further/nono
