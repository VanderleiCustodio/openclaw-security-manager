Novas Features — OpenClaw Security Manager

Selecione as categorias que mais te interessam (multi-seleção)

💬

Novos Canais

Microsoft Teams, Slack, Signal, Instagram DM, Line — configuração de dmPolicy, pairing e grupos para cada plataforma. Atualmente só WhatsApp, Telegram e Discord.

📊

Monitoramento em Tempo Real

Dashboard de eventos ao vivo via SSE/WebSocket, contagem de conexões ativas, latência do gateway, uso de memória/CPU do processo openclaw.

🔔

Alertas & Notificações

Alerta por email, webhook (Slack/Teams/Discord) ou push quando um evento crítico ocorre — docker caiu, permissão negada, tentativa de acesso indevido.

🛡️

Segurança Avançada do Painel

Senha de acesso ao painel web, IP whitelist, sessão com timeout, log de acesso ao próprio manager, HTTPS com certificado local.

🌐

Gateway Avançado

Rate limiting por canal/agente, IP whitelist/blacklist, TLS management, regras de roteamento customizadas, múltiplos endpoints simultaneamente.

🗂️

Multi-Ambiente (Dev/Staging/Prod)

Perfis de configuração separados por ambiente, troca rápida entre eles, diff visual entre dois ambientes, import/export de perfis.

🔗

Integrações Externas

Webhook outbound para eventos, métricas Prometheus, integração com Datadog/Splunk (SIEM), n8n/Zapier triggers, PagerDuty para incidents.

✨

UX & Produtividade

Busca global (⌘K), keyboard shortcuts, wizard de setup inicial, comparação side-by-side de configs, export PDF do relatório de segurança.

🤖

Gestão de Agentes

Lista de agentes ativos, consumo de tokens por agente, histórico de sessões, kill de agente individual, quotas e limites por agente.

📋

Allowlist Visual de DMs

Interface para gerenciar listas de usuários permitidos por canal (WhatsApp, Telegram, Discord) — add/remove com nome, ID e foto.
