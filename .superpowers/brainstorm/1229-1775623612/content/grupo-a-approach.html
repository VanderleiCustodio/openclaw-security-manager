Grupo A — Abordagem de UI

Como implementar Plugins UI, Tool Elevation e Config Diff?

A

Consistente com o padrão atual

Mesma estrutura dos formulários existentes — inputs de texto, selects e toggles. Plugins e allowFrom como campo de texto com vírgulas. Config diff como tabela simples abaixo dos backups.

── Plugins ──────────────────
plugins.allow mcp-github, mcp-slack, mcp-notion
plugins.deny mcp-dangerous
── Tool Elevation ───────────
elevated.enabled ● OFF
elevated.allowFrom human, system

✓ Rápido de implementar · ✓ Zero curva de aprendizado · ✗ Menos visual

B

UI melhorada com chips e diff visual

Tags clicáveis para plugins (add/remove visual). Config diff como painel side-by-side colorido. Tool elevation com lista de fontes permitidas com checkboxes.

── Plugins ──────────────────
plugins.allow
mcp-github × mcp-slack × + add
plugins.deny
mcp-dangerous × + add
── Config Diff ──────────────
- gateway.bind: lan
+ gateway.bind: loopback
- sandbox.mode: off
+ sandbox.mode: non-main

✓ Mais claro e visual · ✓ Diff colorido lado a lado · ✗ Mais trabalho
